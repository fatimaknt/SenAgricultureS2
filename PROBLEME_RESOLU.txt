🔍 ANALYSE DU JOURNAL DES ÉVÉNEMENTS :

L'erreur était dans le fichier App.config :
"L'élément racine du fichier de configuration de 
l'application doit être configuration."

Le fichier commençait par <system.serviceModel> au lieu de :
<?xml version="1.0" encoding="utf-8" ?>
<configuration>
  ...
</configuration>

❌ AVANT (CORROMPU) :
<system.serviceModel>
    <bindings>
        ...

✅ APRÈS (CORRIGÉ) :
<?xml version="1.0" encoding="utf-8" ?>
<configuration>
    <startup>...</startup>
    <system.serviceModel>
        <bindings>
        ...
    </system.serviceModel>
</configuration>

──────────────────────────

précédente. Le fichier commençait directement par
<system.serviceModel> sans l'en-tête XML requis ni la
balise racine <configuration>.

Le journal des événements Windows a permis d'identifier
précisément l'erreur :
"L'élément racine du fichier de configuration de 
l'application doit être configuration."

Cette erreur causait :

- Impossible de démarrer l'EXE
- InvalidOperationException au chargement du service WCF

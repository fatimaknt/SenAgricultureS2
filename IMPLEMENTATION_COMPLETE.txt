🎯 LES 8 TYPES DE MESSAGES D'ERREUR DÉTAILLÉS
═══════════════════════════════════════════════════════════════════════════════

1️⃣  ❌ SERVICE WCF INTROUVABLE (EndpointNotFoundException)
   📍 Quand : Le service WCF n'est pas démarré ou URL incorrecte
   💡 Solution : Démarrer MetierAppSenagriculture (F5) et vérifier l'URL

2️⃣  ❌ ERREUR DE COMMUNICATION (CommunicationException)
   📍 Quand : Service planté ou problème réseau
   💡 Solution : Redémarrer le service WCF, vérifier MySQL

3️⃣  ⏱️ TIMEOUT (TimeoutException)
   📍 Quand : Le service met trop de temps à répondre
   💡 Solution : Optimiser MySQL, augmenter le timeout

4️⃣  ⚠️ CHAMP OBLIGATOIRE (Validation)
   📍 Quand : Un champ requis est vide
   💡 Solution : Remplir tous les champs (focus automatique)

5️⃣  ⚠️ FORMAT INVALIDE (FormatException)
   📍 Quand : Le prix n'est pas un nombre valide
   💡 Solution : Utiliser format correct (1000 ou 2500.50)

6️⃣  ⚠️ PRIX INVALIDE (Validation)
   📍 Quand : Prix négatif ou zéro
   💡 Solution : Saisir un prix positif

7️⃣  ❌ ÉCHEC DE L'AJOUT (bool result = false)
   📍 Quand : Erreur base de données (contrainte, doublon)
   💡 Solution : Vérifier les logs du service WCF

8️⃣  ⚠️ BASE DE DONNÉES VIDE (produits.Length == 0)
   📍 Quand : Aucun produit dans la base
   💡 Solution : Vérifier MySQL, exécuter Database_Setup.sql

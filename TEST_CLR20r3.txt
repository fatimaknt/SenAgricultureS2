🆘 SI UN TEST ÉCHOUE
────────────────────

TEST 1 échoue (crash CLR20r3 persiste) :
❌ Vérifiez que vous avez bien arrêté le debug avant
❌ Supprimez bin\Debug et recompilez
❌ Consultez CLR20r3_FIX.txt section "Résolution de problèmes"

TEST 2 échoue (ne démarre pas avec service) :
❌ Vérifiez que http://localhost:59843/Service1.svc est accessible
❌ Vérifiez App.config (endpoint address correcte)
❌ Consultez les logs dans Fenêtre Sortie

TEST 3 échoue (pas de logs) :
❌ Fenêtre Sortie : sélectionnez "Déboguer" dans le menu
❌ Redémarrez en mode Debug (F5, pas Ctrl+F5)

TEST 4 échoue (erreur lors de l'ajout) :
❌ Vérifiez que MySQL est démarré
❌ Vérifiez la connexion dans Web.config du service
❌ Consultez les logs du service WCF

TEST 5 échoue (pas de validation) :
❌ Vérifiez que le code de Form1.cs est bien à jour
❌ Recompilez le projet

Configuration double (défense en profondeur) :
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  App.config (déclaratif)          Form1.cs (programmatique)│
│        ↓                                    ↓               │
│   10 minutes                            5 minutes           │
│        └────────────┬────────────────────┘                 │
│                     ↓                                       │
│            Timeout effectif = 5 minutes                     │
│            (le minimum des deux)                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘

Avantages de cette approche :
✅ Redondance : Si une config échoue, l'autre prend le relais
✅ Flexibilité : Peut être changé sans recompiler (App.config)
✅ Contrôle : Peut être modifié à l'exécution (programmatique)
✅ Débogage : Logs pour confirmer l'URL utilisée

Si timeout ENCORE dépassé après 5 minutes :
───────────────────────────────────────────
❌ Problème : La requête prend vraiment > 5 minutes

✅ Solutions possibles :
   1. Vérifiez MySQL - Peut-être trop lent ?
      → Consultez les logs MySQL
      → Vérifiez les performances (CPU, RAM)

   2. Testez la requête directement dans MySQL
      → SELECT * FROM produits;
      → Devrait être instantané

   3. Activez les logs dans ProduitController
      → Déjà présents dans votre code !
      → Consultez la Fenêtre Sortie

   4. Augmentez encore le timeout si vraiment nécessaire
      → Changez FromMinutes(5) vers FromMinutes(10)

Si l'URL affichée est incorrecte :
──────────────────────────────────
❌ Problème : L'URL ne correspond pas au service démarré

✅ Solutions :
   1. Vérifiez App.config ligne 39 :
      <endpoint address="http://localhost:59843/Service1.svc"

   2. Vérifiez le port du service WCF démarré
      → Doit correspondre au port dans l'URL

   3. Si port différent, modifiez App.config
      → Changez 59843 vers le bon numéro de port
